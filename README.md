# devops-examples

Hands-on, runnable examples of infra and networking concepts. Each directory is self-contained and runs locally with Docker.

| Example | Concept |
|---|---|
| [haproxy-load-balancing](haproxy-load-balancing/) | HAProxy load balancing across Node.js containers, ACLs |
| [mtls](mtls/) | Mutual TLS between two services with a self-signed CA |
| [db-replication](db-replication/) | MySQL GTID replication + promotion, MongoDB replica set elections and quorum loss |
